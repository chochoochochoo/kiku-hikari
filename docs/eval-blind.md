# ブラインド判定の手順（第三者 3 人・最初に決めておく評価）

目的: 「Claude あり」が「拍連動だけ」「ルール表」より曲に合って見えるかを、作者の感想でなく第三者の判定で示す。

## 3 段（同じ曲・同じ灯体・同じ撮影条件）
| 記号 | モード | 中身 |
|---|---|---|
| ① | `--mode beat` | 拍連動のみ。白・開ゴボ・固定の振り |
| ② | `--mode rules` | ① ＋ 特徴量→色・明るさの直結表（Claude なし・先読みなし） |
| ③ | `--mode claude` | ① ＋ Claude の先読み（色・語彙・溜め・境界で開く） |

## 曲
- 自作曲から拍が明確で構造にひねり（ブレイク・偽サビ）のある 3 曲（`docs/eval-beat.md` の結果から 05・07・09 を候補）。公開するのは CC0 か自作のオリジナルのみ。

## 提示の仕方（順序効果を避ける）
- 1 曲につき 3 本の動画（各 45〜60 秒・同じ区間）。ラベルは A/B/C に匿名化し、曲ごとに割り当てを変える（ラテン方格）。
- 判定者は 3 人。照明の素人でよい（属性を記録: 年代・音楽／照明の経験の有無）。
- 判定者は映像を見てから答える。作者は同席しない（できれば）。

## 質問（1 曲につき）
1. 「サビ（盛り上がり）の頭で、光がちょうど変わった」と感じたのはどれか（A/B/C・複数可）
2. 曲の雰囲気（色）に合っていたのはどれか（A/B/C・1 つ）
3. 一番「人が操作しているよう」に見えたのはどれか（A/B/C・1 つ）
4. 自由記述（任意）

## 集計
- 各質問で ③ が選ばれた割合（3 曲 × 3 人 = 9 票）。正答率でなく「選好率」。
- ③ が ①② に負けた曲と理由を README に書く（隠さない）。
- ログ（`logs/public/`）から ③ の「予測した境界」と「実際の境界（作者が事後に付けた区間 JSON）」の時刻差も併記する（的中率・平均誤差）。

## 記録
- 判定シート: `docs/blind-sheet.csv`（曲, ラベル, 実モード, 判定者, Q1, Q2, Q3, 自由記述）
- 判定者は貢献者ではない（運営 FAQ Q21）。リポジトリにはコミットさせない。
